# IMF Data Science Community

A collaborative space for past, current, and future IMF Data Science students and alumni to share knowledge, projects, exercises, resources, and career guidance.

## What you can find here

- Python, SQL, statistics, machine learning, AI, Power BI, and Big Data resources
- Exercises, notebooks, datasets, and practical examples
- Student projects and final project (TFM) references
- Portfolio, interview, and job-search resources

## Future-friendly structure

```text
resources/
  python/ sql/ statistics/ machine-learning/ artificial-intelligence/
  data-visualization/ power-bi/ big-data/
exercises/
projects/
  student-projects/ final-projects-tfm/
datasets/
career/
  portfolio/ interviews/ job-resources/
```

Each contribution should include a short README explaining its purpose, setup, data source, and license.

## Contributing

Everyone in the IMF Data Science community is welcome to contribute. Add clear documentation, respect licenses and privacy, and place content in the most relevant folder. Please be respectful, constructive, and inclusive.
